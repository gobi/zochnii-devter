# Зочны дэвтэр

Дэлгүүрийн үйлчлүүлэгчид сэтгэгдлээ үлдээдэг нэг хуудас веб апп.

## Юу хийдэг вэ

- Нэр, сэтгэгдлээ бичээд «Үлдээх» дарахад жагсаалтад нэмэгдэнэ
- Сэтгэгдлийг Supabase-ийн санд хадгална — бүх зочин бие биеийнхээ сэтгэгдлийг харна
- Хоосон эсвэл хэт урт (нэр 50, сэтгэгдэл 500 тэмдэгтээс дээш) оролтыг хүлээж авахгүй, алдааг талбарын доор харуулна. Энэ хязгаарыг сан дээр давхар шалгана
- Зочны бичсэн зүйлийг зөвхөн текст хэлбэрээр харуулна (код болж ажиллахгүй)
- Интернэтгүй эсвэл сан хариу өгөхгүй үед монгол мэдэгдэл гаргана

## Хаана байгаа вэ

- Амьд хуудас: https://gobi.github.io/zochnii-devter/ (GitHub Pages)
- Сэтгэгдлүүд: Supabase-ийн `comments` хүснэгт

## Эрх

- Зочин (нэвтрээгүй хүн) сэтгэгдэл **унших, нэмэх** эрхтэй; засах, устгах эрхгүй (`schema.sql` дахь RLS дүрэм)
- `app.js` доторх түлхүүр нь Supabase-ийн нийтийн (publishable) түлхүүр — ил байх нь хэвийн
- Зохисгүй сэтгэгдлийг эзэн Supabase-ийн самбар (Table Editor)-оос устгана

## Хязгаарлалт

- Сүүлийн 200 сэтгэгдлийг л харуулна.
- Спамаас хамгаалах хязгаар байхгүй — нэг хүн олон сэтгэгдэл дараалан бичиж чадна.
- Автомат тест байхгүй.

## Яаж ажиллуулах вэ

`index.html` файлыг browser-т нээнэ (интернэт хэрэгтэй).

Шинэ Supabase төсөл дээр суулгах бол: `schema.sql`-ийг самбарын SQL Editor-т ажиллуулж, `app.js` дээрх `SUPABASE_URL`, `SUPABASE_KEY` хоёрыг өөрийн төслийнхөөр солино.
