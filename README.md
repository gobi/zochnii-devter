# Зочны дэвтэр

Дэлгүүрийн үйлчлүүлэгчид сэтгэгдлээ үлдээдэг нэг хуудас веб апп.

## Юу хийдэг вэ

- Нэр, сэтгэгдлээ бичээд «Үлдээх» дарахад жагсаалтад нэмэгдэнэ
- Хоосон эсвэл хэт урт (нэр 50, сэтгэгдэл 500 тэмдэгтээс дээш) оролтыг хүлээж авахгүй, алдааг талбарын доор харуулна
- Зочны бичсэн зүйлийг зөвхөн текст хэлбэрээр харуулна (код болж ажиллахгүй)

## Хязгаарлалт

- Сэтгэгдэл зөвхөн бичсэн төхөөрөмжийн browser-т (localStorage) хадгалагдана. Өөр төхөөрөмж, өөр browser-оос харагдахгүй — дэлгүүрийн нэг таблет дээр ашиглахад тохирно.
- Автомат тест байхгүй.

## Яаж ажиллуулах вэ

`index.html` файлыг browser-т нээнэ.
